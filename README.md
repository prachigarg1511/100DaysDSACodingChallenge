# 🚀 100 Days of DSA Coding Challenge

Welcome to my **100 Days of DSA Coding Challenge**! 🎯

This repository documents my journey of solving **Data Structures and Algorithms (DSA) problems consistently for 100 days**.

The goal is to build strong problem-solving skills, improve algorithmic thinking, understand different data structures, and become more confident in technical interviews and competitive programming.

---

## 🎯 Challenge Goals

* 📌 Solve DSA problems consistently for 100 days
* 🧠 Improve logical and problem-solving skills
* 💻 Strengthen C++ programming fundamentals
* 📚 Master important Data Structures & Algorithms
* ⚡ Learn to write optimized and efficient solutions
* 🎯 Prepare for coding interviews and placements
* 📈 Track my progress and learning journey

---

## 💡 My Approach

For every problem, I try to focus on:

1. Understanding the problem
2. Identifying the appropriate approach
3. Writing a clean solution
4. Analyzing **Time Complexity**
5. Analyzing **Space Complexity**
6. Understanding possible edge cases
7. Improving the solution whenever possible

## 📈 Why 100 Days?
